# Bootsbaza — ИИ-бот для Instagram Direct

ИИ-консультант магазина Bootsbaza для Instagram Direct: сам консультирует,
подбирает товары, присылает клиенту фото и ссылки с сайта, оформляет заказ и
отправляет его менеджерам в Telegram-группу, а по просьбе клиента подключает
живого менеджера (уведомление в ту же группу).

## Главное про архитектуру

Бот **полностью изолирован от сайта**:

- лежит в отдельной папке `bot/` со своим `package.json` и зависимостями;
- **не** импортирует код сайта и **не** лезет в Google-таблицу;
- берёт актуальный каталог только по HTTP — `GET ${SITE_URL}/api/catalog`
  (там уже нет оптовых цен, только цена для покупателя);
- заказы и вызов менеджера уходят в Telegram-группу.

Поэтому бот **не может сломать сайт**, а сайт и бот дорабатываются независимо.
Чтобы вынести бота в **отдельный репозиторий** — просто скопируйте папку `bot/`
целиком, там всё самодостаточно.

```
bot/
├─ src/
│  ├─ server.ts      — HTTP-сервер, вебхуки Instagram
│  ├─ agent.ts       — ИИ-консультант (Claude + петля инструментов)
│  ├─ tools.ts       — что бот умеет: поиск, карточка, заказ, зов менеджера
│  ├─ catalog.ts     — клиент каталога (${SITE_URL}/api/catalog + кэш)
│  ├─ instagram.ts   — Send API + разбор вебхуков
│  ├─ telegram.ts    — уведомления в группу менеджеров
│  ├─ sessions.ts    — история диалога по каждому клиенту (в памяти)
│  └─ config.ts      — переменные окружения
├─ .env.example
└─ package.json
```

## Что нужно получить заранее (внешние доступы)

1. **Anthropic API key** — `ANTHROPIC_API_KEY` (console.anthropic.com). Это платный
   ИИ, оплачивается по токенам.
2. **Instagram/Meta:**
   - бизнес-аккаунт Instagram, привязанный к странице Facebook;
   - приложение в [Meta App Dashboard](https://developers.facebook.com/) с продуктом
     **Instagram** (Messaging);
   - **токен доступа** (`IG_ACCESS_TOKEN`) с разрешениями
     `instagram_business_manage_messages` (и связанными);
   - **App Secret** (`META_APP_SECRET`) — для проверки подписи вебхуков;
   - бизнес-верификация приложения Meta (нужна для работы в проде с реальными
     пользователями).
3. **Telegram** — токен бота (`TELEGRAM_BOT_TOKEN`) и `TELEGRAM_CHAT_ID` группы.
   Можно те же, что на сайте.
4. **Публичный HTTPS-адрес** для вебхука (хостинг бота: Railway, Render, Fly.io,
   VPS и т.п.). Meta требует HTTPS.

## Настройка

```bash
cd bot
cp .env.example .env    # заполните ключи
npm install
npm run dev             # боевой сервер (нужны переменные Instagram)
```

Проверка сборки без запуска: `npm run typecheck`.

## Локальный тест без Instagram

Можно пообщаться с ботом прямо в консоли, ещё до подключения Директа —
нужны только `ANTHROPIC_API_KEY`, `SITE_URL` и Telegram (для оформления заказа):

```bash
cd bot
cp .env.example .env    # достаточно заполнить ANTHROPIC_API_KEY, SITE_URL, TELEGRAM_*
npm install
npm run chat
```

Пишете как клиент — бот консультирует, «карточки товаров» печатаются в консоль,
а реальные заказы и вызов менеджера уходят в вашу Telegram-группу. Так виден
весь путь продажи без настройки Meta.

## Подключение вебхука в Meta

1. Разверните бота на публичном HTTPS-адресе (например `https://bot.bootsbaza.com`).
2. В Meta App Dashboard → Instagram → Webhooks укажите:
   - **Callback URL:** `https://<ваш-адрес>/webhook`
   - **Verify Token:** значение `IG_VERIFY_TOKEN` из `.env`
3. Подпишитесь на поле `messages`.
4. Напишите аккаунту в Директ — бот ответит.

## Как это работает

- Клиент пишет в Директ → Meta шлёт вебхук на `/webhook`.
- Бот ведёт диалог через Claude (`claude-opus-4-8`) с инструментами:
  - `search_products` — поиск по каталогу сайта;
  - `send_product_card` — присылает клиенту фото + цену + ссылку;
  - `create_order` — оформляет заказ → в Telegram-группу;
  - `request_human` — уведомляет группу и **ставит диалог на паузу** (бот замолкает,
    менеджер отвечает в Директе вручную).
- История диалога хранится в памяти по каждому клиенту (6 часов). Для нескольких
  инстансов замените Map в `sessions.ts` на Redis.

## Стоимость и заметки

- ИИ платный (по токенам Anthropic). Диалоги короткие, но следите за расходом.
- После `request_human` бот по этому клиенту молчит до истечения сессии (6 ч
  бездействия). При необходимости добавьте команду «возобновить» для менеджера.
- Вложения от клиента (только фото без текста) пока не обрабатываются — легко
  добавить в `instagram.ts` → `parseIncoming`.
